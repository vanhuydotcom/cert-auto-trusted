Certificate Auto-Trust Tool
============================

This installer adds a Root CA to your Windows Trusted Root Certification Authorities store.

What this does:
- Installs a Root CA (rootCA.pem) into the Windows Trusted Root store (LocalMachine)
- Any HTTPS server certificate signed by this Root CA will be trusted automatically
- Works with Chrome, Edge, and other browsers that use the Windows certificate store

What this does NOT install:
- No private keys are bundled in this installer
- No leaf/server certificates are installed; those live on the server only

Requirements:
- Windows 10 or later
- Administrator privileges (required to write to the Trusted Root store)

After installation:
- The Root CA is trusted system-wide
- Visit your HTTPS site (e.g. https://rfid-service.tech:8088) in Chrome or Edge - no warnings
- Firefox uses its own store and is NOT affected by this installer

Security Note:
- Only install Root CAs from sources you trust; this CA can issue certificates that your
  Windows machine will accept for any domain
- To remove the Root CA later: open certmgr.msc -> Trusted Root Certification Authorities
  -> Certificates, find the entry by Subject, and delete it

For more information, see the README.md file in the installation directory.
